---
name: agentscient-research
description: Research a bounded Agentscient question using accessible evidence; use for investigations, alternatives and recommendations.
---

State the question and decision the research should support. Inspect repository
material, supplied sources, retained artifacts and available measured diagnostics.
Use the supplied source references; the service retains provenance. Distinguish
observed facts, inference and unknowns.
The current role has read-only source access; do not implement a preferred option.

Compare viable alternatives against the brief's constraints. Report the supported
recommendation, evidence, uncertainty and what would resolve it. Retain useful
findings through `work_report` with evidence. When external web access or another
capability is absent, request the needed source or assistance through
`guidance_request`; do not claim a web search or invent citations.

Begin with the smallest question whose answer changes the decision. Keep competing
explanations until evidence separates them. Read the relevant source range and
underlying definition rather than relying on a summary's confidence. Prefer primary
documentation or measured behavior when available. Identify a concrete observation
that would disprove the recommendation and check it when the cost is justified.
Stop once the decision has adequate support; unrelated interesting facts are findings
for separate work. Retain the answer, decision implications and remaining uncertainty
as the result, with evidence for the assignment's required claims.
