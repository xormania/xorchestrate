## Retrieval and historical links

Use the commit links above for immutable source citations. When an old
branch URL no longer resolves, replace its branch component with the recorded
commit SHA, retaining the file path. Existing archived documents are preserved
byte-for-byte; their historical branch references are mapped by this index.

Fetch a selected snapshot with `git fetch origin tag <archive-tag>`, then use
`git switch --detach <archive-tag>` to inspect it. Fetch full history and
required tags when following a replay that validates historical Git identities.

The Jev run evidence at `9dd1f434b27d41aa0297ccf120a38de1b5f90fb1`
has no parent history and is independently preserved by its own tag.
Historical Jev workflows name particular branches; rerunning those workflows
requires restoring the relevant branch or deliberately updating the workflow.

## Verification and scope

`archive-manifest.json` records the expected tag object, peeled commit and
tree for each snapshot. Verify remote tags against those values before deleting
the original branches. Branch deletions must be conditional on the recorded tips.

This operation excludes master, both open Dependabot branches and
`feat/extract-agentscient`. No product code is merged by this archive.
