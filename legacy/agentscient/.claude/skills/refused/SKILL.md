---
name: refused
description: Diagnose a failed operation or repository warning and find a practical next step. Use when work encounters an error or a diagnostic finding.
---

Read the actual error and identify which operation failed. A repository hook
finding is advisory; explain the concrete issue and use judgment about the remedy.
If the diagnostic itself failed, say what could not be checked and continue work.

Do not recreate retired hand grants, compulsory dispatcher identity, or mandatory
pipeline routing. Follow current owner intent and `AGENTS.md`. Native harness
permissions and tool input validation have their own mechanisms; report a real
access limitation accurately instead of treating it as a workflow requirement.

For a failed CI check, inspect its output and fix the relevant behavior or an
obsolete expectation. Do not manufacture a pass. Owner recovery is outside agent
automation; it is not a command or flag agents can issue.
