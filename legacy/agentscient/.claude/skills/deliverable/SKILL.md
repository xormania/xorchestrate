---
name: deliverable
description: Use the optional deliverable record to track a concrete goal across sessions or collaborating agents.
---

Start from the owner's current objective. Read `AGENTS.md` for working guidance.
Use a deliverable record when it helps coordination or makes an outcome measurable.
It is not permission to work and need not be created before editing or branching.

`python3 ops/conductor/tools/deliverable.py show --unmeasured` reads the current
record without executing its measures. Inspect existing work before adding a
competing assignment. Use `add`, `set`, or `remove` only when maintaining a record
is useful to the task. Explain any consequential difference between the record
and current owner direction; the current direction governs.

At handoff, report the actual result and remaining work. Run a target measure
when it supplies useful evidence, and distinguish a missing reading from success.
No hand grant, lock ceremony, or prescribed completion phrase is required.
