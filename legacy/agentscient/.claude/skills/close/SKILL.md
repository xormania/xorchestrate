---
name: close
description: Report a session's measured outcome and useful handoff context when finishing or handing work to another agent.
---

Lead with the result relative to the owner's objective. Include the relevant
branch or PR, checks actually run, and any material limitation or remaining work.
A draft, a passing check, and a merged change are different outcomes; say which
one occurred. Preserve unrelated work and identify unfinished changes someone
needs to pick up.

Use the existing board, Git, CI, findings, and optional deliverable readings when
they answer a question that matters to the handoff. Do not run a fixed inventory
of every store or create records solely to satisfy an old closing procedure.
Keep useful observations for learning, including unnecessary workflow friction.

Follow `AGENTS.md`. There is no grant to settle and no Stop approval to obtain.
