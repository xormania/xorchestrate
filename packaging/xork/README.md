# xork

`xork` is a short install name for
[xorchestrate](https://github.com/xormania/xorchestrate). It contains no code:
its only dependency is the release of `xorchestrate` with exactly the same
version, and it provides the same commands, `xo` and `xorchestrate`.

```sh
uv tool install xork      # or: pipx install xork
xo --version
```

See the [install guide](https://github.com/xormania/xorchestrate/blob/master/docs/install.md).
